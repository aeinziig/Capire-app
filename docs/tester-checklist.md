# CAPIRE Peer Test Checklist

## Install

- Install the APK successfully
- Open the app without crash on launch

## Authentication

- Log in with a valid SPCBA account
- Try forgot password flow
- Check that institutional email placeholders are generic and correct

## Home and Search

- Home screen loads without broken layout
- `See all` from recommended topics opens Search
- Search loads capstones and opens capstone details

## Capstones

- Open at least 3 capstone detail pages
- Save and unsave bookmarks
- Generate a citation from capstone details

## Originality

- Run originality check with pasted text
- If file upload is being tested, verify upload and result flow

## Chatbot

- Ask for all 24 capstone titles
- Ask for topic ideas
- Ask for citation help

## User Messaging

- Start a conversation
- Send and receive messages
- Confirm unread badge appears
- Open the conversation and confirm unread badge clears after seen
- Long-press a conversation and test `Archive`
- Open archived section and test `Unarchive`
- Long-press a conversation and test `Delete`

## Profile and Settings

- Update display name
- Update display profile
- Toggle light/dark mode
- Toggle do not disturb
- Open Terms of Use and Privacy Policy

## Report Any Blockers

- Crash
- Infinite loading
- Broken navigation
- Missing data
- Wrong badge state
- Messages not updating in real time
- Text not visible in dark mode
