## What Testers Should Expect

- SPCBA login flow using 8-digit institutional email format
- Capstone search and capstone detail browsing
- Bookmark saving and viewing
- Originality checking against archive data
- Gemini-powered chatbot replies
- User-to-user chat with unread badges, seen state, archive, delete, and unarchive behavior
- Profile customization, settings, theme switching, and do not disturb mode

## Known Limits

- Conversation archive and delete are per-user inbox actions, not global message deletion
- This is a peer test release, not the final public release
